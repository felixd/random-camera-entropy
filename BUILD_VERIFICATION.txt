Integrated buffered-source changes
- USB agent keeps V4L2 capture open and continuously drains frames while exposing source uptime/warm-up metadata.
- Recorder stores full Y8 or packed whole-frame LSB data in committed chunks with a configurable limit (300 GB by default).
- frame-buffer-latest is available during recording; frame-buffer-latest-complete points to the latest cleanly closed dataset.
- dataset-y can replay a stopped dataset or follow a growing dataset without consuming a partial frame.
- The default source path is relative: data/frame-buffer-latest.
- Control-server dataset preflight resolves relative paths from the project root, reads geometry from manifest.json and validates frames.csv.
- Job startup uses PID as PGID with start_new_session=True, avoiding the os.getpgid() race and generic HTML 500 responses.

Web-control fix

- Localized number fields are serialized through valueAsNumber before being sent to the API.
- The backend additionally accepts a decimal comma from older clients or direct API calls.
